# React Lab

A hands-on React and TypeScript practice path for developers preparing at around four years of experience. It includes a searchable curriculum of progressively challenging exercises, senior-level notes, and locally saved completion progress.

## Start

```bash
npm install
npm run dev
```

Use the curriculum to select a challenge, review its example code, and try the interactive preview before building your own solution. Examples are starter patterns, not full solutions: adapt them to the requirements and edge cases. Mark a practice complete when you can explain the decisions and trade-offs. Your completed practice IDs are saved in browser local storage.

The companion [four-year React practice notes](./note.md) contains a suggested study schedule, concept summaries, and interview preparation prompts.

## Curriculum

The practice path covers:

- Components, props, state, rendering, collections, and forms
- Hooks, effects, async requests, context, reducers, and routing
- TypeScript, accessibility, testing, error handling, and performance
- Pagination, optimistic updates, reusable component APIs, and a capstone issue tracker

## Quality checks

```bash
npm run build
```
